# Frontend Technology Stack Conventions

## Core Frameworks

### Svelte 5
- **Version**: Svelte 5 (latest stable)
- **Key Features**: Utilize Runes for elegant state management
- **Code Style**: Write clean, modern, idiomatic Svelte 5 code

### UI Toolkit
- **Framework**: Skeleton 3
- **Usage**: Leverage components, actions, and utilities to accelerate development
- **Design System**: Adhere to Skeleton's design system for consistent visual experience

### Styling Framework
- **CSS Framework**: Tailwind CSS 4
- **Theme Capabilities**: Utilize color layering, theme switching, and seamless dark mode

## Development Principles

### State Management
- Prioritize Svelte 5 Runes for state management
- For complex state, consider Svelte's stores pattern
- Avoid over-engineering, maintain simplicity in state management

### Component Design
- Follow single responsibility principle
- Components should have clear input/output interfaces
- Prefer composition over inheritance

### Performance Optimization
- Leverage Svelte's compile-time optimizations
- Use lazy loading and code splitting appropriately
- Focus on bundle size and loading performance
